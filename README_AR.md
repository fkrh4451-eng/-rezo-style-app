# REZO STYLE APP — النسخة المجانية الثابتة

هذه نسخة عرض مجانية (Static) يمكن نشرها على GitHub Pages بدون قاعدة بيانات أو بطاقة دفع.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub باسم `rezo-style-app`.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، وبالأخص `index.html` ومجلد `rezo_style_assets`.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر `main` والمجلد `/(root)` ثم Save.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## حدود النسخة
- الموقع واجهة عرض تجريبية، وليس متجراً يستقبل طلبات حقيقية.
- الحسابات، المشاركات المجتمعية المتصلة بقاعدة البيانات، وحفظ الطلبات غير مفعّلة.
- الدفع الإلكتروني غير مفعّل.
- لا تجمع بيانات شخصية أو كلمات مرور أو بيانات بطاقات في هذه النسخة.

يمكن تطوير النسخة لاحقاً وربطها بقاعدة بيانات واستضافة مناسبة.
